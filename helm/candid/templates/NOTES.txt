Build & push images before your first install:

  # From repo root
  docker build -t {{ .Values.backend.image.repository }}:{{ .Values.backend.image.tag }} ./backend
  docker build -t {{ .Values.frontend.image.repository }}:{{ .Values.frontend.image.tag }} ./ui/frontend

  docker push {{ .Values.backend.image.repository }}:{{ .Values.backend.image.tag }}
  docker push {{ .Values.frontend.image.repository }}:{{ .Values.frontend.image.tag }}

To upgrade after code changes:
  helm upgrade candid ./helm/candid -f your-values.yaml

⚠  The backend uses an in-memory store. All active games are lost on pod restart.
